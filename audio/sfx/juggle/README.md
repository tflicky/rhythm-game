# Juggling sounds

Name each file after its slot (`.wav` / `.ogg` / `.mp3`). Until a file exists a
placeholder plays. Trim them right up to the attack so they land on the beat.

| Slot | When |
|------|------|
| `call` | the juggler's "hup" on each catch of the call bar (shows you the rhythm) |
| `stop_call` | the downbeat of an act's last bar: "finish this bar, then stop" |
| `catch` | your catch (falls back to the monkey level's `catch.wav`) |
| `drop` | a missed catch hits the ground |
| `curtain` | (not used yet) the curtain between acts |
