## Code word: "wrap up"
When I say "wrap up":
1. Add a dated entry to DEVLOG.md: what we changed, what broke and how we fixed it, and anything I said that would be good for my YouTube video (my own words, quoted).
2. Commit all changes to git with a clear message.
3. Tell me in 2-3 lines what got saved.
4. If anything from today is worth recording for my YouTube video (a before/after, a bug, a new feature working), suggest the clips in one line each. If it was a quiet day, just say "Nothing to record today."
